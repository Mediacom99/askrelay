Developer A's AI session sends a question to colleague B; B approves; B's AI
answers with **its own live context** — no human copy-paste, no shared session,
no vendor lock-in. A thin self-hostable relay (single Go binary + SQLite) speaks
MCP over HTTPS with OAuth 2.1, so claude.ai, ChatGPT, and Claude Code all connect.

<CardGrid stagger>
	<Card title="Approval-gated both ways" icon="approve-check">
		No one's AI acts on — or answers — another person's message without a
		human tap. Per-message by default; revocable per-thread grants.
	</Card>
	<Card title="Cross-vendor" icon="puzzle">
		Claude Code ↔ claude.ai ↔ ChatGPT. One relay bridges a mixed-tooling team
		without forcing everyone onto one AI.
	</Card>
	<Card title="Self-hosted & ephemeral" icon="setting">
		One binary + SQLite on your own infra. The relay never sees vendor
		credentials, and coordination state is ephemeral.
	</Card>
	<Card title="Answers from live context" icon="rocket">
		The value isn't a shared wiki — it's a teammate's AI answering from the
		code and context it's in right now.
	</Card>
</CardGrid>

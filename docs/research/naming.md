> GitHub (org + repo search), npm, domains (.dev/.io/.com/.sh), existing products,

> the survivors. Winner signed off by the maintainer: **askrelay** (D-18).

## Winner: askrelay — full collision report

- **verdict:** MINOR_COLLISIONS
- **github:** org/user github.com/askrelay does not exist (404 via web and gh api). GitHub repo search finds no repo named askrelay; only hit is mGungorr/relay-legal (0 stars, HTML, legal docs for some relay service that uses askrelay@gmail.com as support email) — unrelated, no activity of note.
- **npm:** registry.npmjs.org/askrelay returns 404 — package name free. (PyPI not checked.)
- **domains:** askrelay.dev: unregistered (Google registry RDAP 404). askrelay.sh: unregistered (RDAP 404). askrelay.io: whois "Domain not found" — available. askrelay.com: REGISTERED 2026-07-02 (two weeks ago) via Gname 057 Inc; DNS resolves to Afternic-style parking IPs (13.248.169.48 / 76.223.54.146) and HTTPS serves no content — appears parked/squatted, no active site.
- **existing_products:** No software, AI/agent tool, protocol, or company named "askrelay" found in web searches (general + AI/MCP/developer-scoped). Adjacent names exist but are distinct: Relay.app (AI workflow automation), RelayPro, RelayThat, Relay Studio — all "Relay", none "askrelay". The one askrelay@gmail.com sighting is a mobile-app legal-docs repo, not a devtool.
- **trademark_knockout:** No "askrelay" trademark hits in web search; closest result was unrelated ASKROI (Riskon International, AI software). Knockout web scan only — not a USPTO/EUIPO database search and not legal advice.
- **notes:** Name is essentially clear for a devtool: GitHub org, npm, and .dev/.io/.sh all appear free, no confusable products or repos in the AI/devtools space. The only collision is askrelay.com, freshly registered (2026-07-02) and parked — likely a squatter; you could launch on .dev/.io and ignore or later negotiate for .com. Unreachable/RDAP-404 domains are strong-but-not-authoritative evidence of availability — confirm at a registrar before announcing. Broader "Relay"-family products (Relay.app etc.) exist in AI automation, so some conversational adjacency at conferences, but "askrelay" itself is distinct. Trademark scan was web-only; a proper USPTO class 9/42 search is still advisable before launch.
- **rationale:** The core verb of the product (one agent asks another) fused with the architecture (a small relay). Reads as 'relay for asks', 8 letters, unambiguous aloud; web check found no project of this name.
